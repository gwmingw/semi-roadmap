## 📌 프로젝트 개요

### 1. 서비스명

> **반도체 취준생을 위한 스펙 진단 및 성장 로드맵 추천 서비스**

### 2. 기획 배경 (Problem)

* **경험 연결의 어려움:** 반도체 취업 준비생들은 기업의 요구사항(JD)을 이해하기 어렵고, 본인의 경험을 직무 역량과 매칭하는 데 한계를 느낌.
* **기존 서비스의 한계:** 범용 LLM은 단일 채용공고 분석에 그치며, 산업·직무 전반을 아우르는 인사이트나 체계적인 역량 프레임워크를 제공하지 못함.

### 3. 핵심 아이디어 (Solution)

* 다량의 채용공고(JD) 데이터를 분석하여 **산업 및 직무 특화 역량 체계**를 도출.
* 이를 기반으로 **JD 해석 ➡️ 경험 매칭 ➡️ 갭(Gap) 분석 ➡️ 맞춤형 성장 로드맵**을 제공.

## ⚙️ 데이터 파이프라인 프로세스

```
[데이터 수집] ➡️ [데이터 전처리] ➡️ [핵심 역량 도출] ➡️ [AI 에이전트 평가 및 컨설팅]

```

| 단계 | 주요 내용 | 활용 기술 및 방법 |
| --- | --- | --- |
| **1. 데이터 수집** | 삼성전자/SK하이닉스 3개년 채용공고 및 직무기술서 확보 | Streamlit 기반 로컬 웹 앱 (수동 입력 및 구조화 파싱 후 CSV 저장) |
| **2. 데이터 전처리** | 텍스트 의미 단위 분해 및 중요 단어 가중치 계산 | `kiwi` 형태소 분석기(토큰화), `TF-IDF` 벡터화(임베딩) |
| **3. 역량 도출** | 유사 키워드 그룹화 및 최적 군집 수 설정 | `DBSCAN 클러스터링`, `실루엣 계수` 평가 및 시각화 |

## 🤖 AI 에이전트 설계 아키텍처 (Solar LLM 활용)

사전에 도출된 핵심 역량 프레임워크를 바탕으로 [HR 평가] ➡️ [스펙 컨설팅]으로 이어지는 2단계 에이전트 시스템입니다.

### 1️⃣ HR 에이전트: 지원자 이력 평가

> **"20년 경력의 깐깐하고 예리한 수석 채용 면접관"**

* **목적:** 역량 프레임워크를 기준으로 지원자의 이력서/포트폴리오를 객관적·엄격하게 평가
* **입력 데이터 (`Input`):**
* 목표 직무 (`{target_job}`)
* 역량 프레임워크 (`{competency_framework}`)
* 지원자 이력서 (`{resume_text}`)


* **핵심 지침:**
* 이력서 내용을 세부 역량과 매칭하여 **1~5점 척도로 엄격하게 채점** (단순 기술 나열은 1~2점).
* 구체적 경험, 수치적 성과, 트러블슈팅 근거를 기반으로 **1~2문장의 명확한 이유(Evidence) 작성**.
* 직무 적합 여부를 판별하는 **총평** 필수 포함.


* **출력 형식 (`Output`):**
* 부가 설명이 없는 **순수 JSON 문자열** (API 연동용)
* 포맷 예시: 역량별 점수 및 이유, 100점 만점 환산 점수, 컬처핏 통과 여부(`True/False`), 종합 요약



---

### 2️⃣ 컨설팅 에이전트: 보완점 및 성장 로드맵 제시

> **"서류 합격과 면접관 매료를 목적으로 하는 수석 스펙 빌딩 전략가"**

* **목적:** HR 평가 결과를 분석하여 부족한 역량을 보완하고 합격률을 극대화할 3개월 단기 스펙 로드맵 제시
* **입력 데이터 (`Input`):**
* 목표 직무 (`{target_job}`)
* 1단계 HR 에이전트의 평가 결과 (`{hr_evaluation_json}`)


* **핵심 지침:**
* **현실적이고 냉정한 어조**로 현재 이력서의 탈락 리스크와 스펙의 빈약함을 진단.
* 추상적인 조언 대신 **당장 이력서에 쓸 수 있는 가시적 스펙** 위주로 제안.
* 1~3개월 차 마일스톤 설계 (정량 스펙 ➡️ 대외활동/교육 ➡️ 공모전/포트폴리오).
* 단기간에 효율을 낼 수 있는 **'가성비 좋은 대외활동/공모전'** 추천 및 이력서 작성 예시 제공.


* **출력 형식 (`Output`):**
* 가독성이 높은 **마크다운(Markdown) 보고서 형태**
* 포함 항목: 이력서 경쟁력 진단, 3개월 단기 로드맵, 추천 가성비 스펙업 활동, 내일 당장 해야 할 최우선 실행 과제(Next Action)
